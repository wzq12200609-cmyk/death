CueSplice

Music cuts for dance rehearsal.

Trim your own music, arrange excerpts in performance order, add gaps or crossfades, and export a rehearsal mix you can revise later.

Start a rehearsal mix

  1. Open the demo to try the editor with original sample music, or create a project and import your own unprotected local audio.
  2. Tap a clip to trim its start and end. Preview and apply the edit.
  3. Drag the reorder handle to change the playing order. Adjust volume, gaps and crossfades as needed.
  4. Export WAV or M4A using the system share sheet.

Free and Pro

Create two personal projects free with every editing tool and WAV/M4A export. The reusable demo does not use the allowance. One optional non-consumable purchase unlocks unlimited new projects. There is no subscription; the price is shown by the App Store. Each project supports up to 20 clips and a 10-minute output.

Restore a purchase

Open Settings → Project access → Restore Purchases using the Apple account that made the purchase. When an active purchase is already verified, the page shows your current benefits.

Keep editable backups

A mixed WAV/M4A is a finished audio file. A complete project backup also contains the source audio and clip settings so you can restore and continue editing. Keep a complete backup of important projects.

Missing source audio

Keep the existing project and any original music or complete backups. A missing audio file cannot be reconstructed from clip settings alone. Restoring a complete project backup can recover its included source audio. Contact support before deleting a project you want to recover.

Supported files

Import local audio supported by Apple’s audio frameworks, such as WAV, M4A and MP3. Streaming-service downloads and DRM-protected tracks are not supported. Source files are limited to 100 MB and 20 minutes each. Full project backups have a 50 MiB aggregate source-audio limit.
